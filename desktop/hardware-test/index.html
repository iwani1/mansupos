Barcode scanner

Use a USB/Bluetooth scanner set to keyboard (HID) mode with an Enter suffix. Scan a known label; check that the code below matches exactly.

02

80 mm receipt printer

Install the trusted Windows driver and set 80 mm paper. The button opens the normal print dialog; it never sends raw printer commands.

Check the two edges, readability, paper width and cut. The slip contains no price, payment, order or real customer details.

03

Cash drawer

This app cannot open a drawer directly. If a drawer is connected to the printer, its driver may open it when the test slip prints; otherwise mark it unsupported.

Do not connect the drawer cable directly to the PC. Note whether it opened, stayed closed, or was not present.

Send back: scanner code/Enter result, printer width/readability/cut, and drawer result. Close this app after the check; results are not saved or uploaded.
